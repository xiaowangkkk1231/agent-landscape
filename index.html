Agent 学习路线：从第一个循环到可靠评测

按顺序学习；链接优先指向课程发布方、框架维护者和基准官方页面。

1. 先判断要不要 Agent：Building effective agents · Anthropic
先区分固定 workflow 与由模型决定下一步的 Agent，再学提示词链、路由、并行、编排器-工作者和评估器-优化器。练习：同一个任务画两种方案，并说明为什么选最简单够用的一种。
2. 做第一个工具 Agent：AI Agents Course · Hugging Face
从 Think → Act → Observe 学工具调用与 Agent loop，用 smolagents 构建并发布 Alfred。适合初学者；包含练习和单元测验。
3. 学会状态、恢复与人工介入：AI Agents in LangGraph · DeepLearning.AI / LangChain
约 1 小时 47 分，先手写 Agent 再用 LangGraph 重建，覆盖持久化、streaming、人类介入。练习：做一个中断后可恢复、关键动作需审批的研究流程。
4. 横向比较官方开发栈 · OpenAI Agents SDK · Google ADK · Microsoft Agent Framework
对照 tools、handoffs、sessions、workflows、guardrails 与 tracing；先用各自官方 quickstart 做同一个小任务，不要只凭教程截图选框架。
5. 用外部基准验证，而不是让 Agent 自己打分 · SWE-bench · OSWorld · WebArena · τ-bench · Terminal-Bench
按任务选编码、桌面、浏览器、工具交互或终端基准。先跑单个样例并记录环境、模型、工具、完整轨迹、成功率、重试、耗时和成本；榜单只在配置可比时参考。

项目练习：① 最小工具 Agent（schema、超时、步数上限）；② 可恢复的研究 Agent（搜索、引用、草稿、事实检查）；③ 小型编码 Agent（外部测试验收）。先定位单 Agent 的具体失败，再决定是否需要多 Agent。
